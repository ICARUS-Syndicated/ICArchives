# 附录 - 云梦废稿剧情（air）

这个世界没有人会死，但不允许生殖。  
这个世界存在了超过万年，其中的人依旧是最初的一批，一个不多，一个不少。  
梦境不允许任何不稳定因素，未知因素，有害因素(不允许进入，出现即抹除，主角通过学到的魔法躲过了检测)  
所谓“极乐”是由云吸走了负面情绪并提供正面情绪，人人都会保持着“极乐”。  
来自外界的“神”发现了这个世界，他们尝试启示这里的人们脱离梦境，有人被劝动，但下一瞬就化为了飞灰。有人不听劝，完全无视了他们，他们没有受任何伤害，不过将“神”的传说传了开来。此后“神”改变了策略，占据了一所学院，通过各种手段培养并教导梦中有魔法天赋的人，准备从内部破开梦境。  
主角是一个普通的不能再普通的人，唯一优点是魔法天赋较高，某天走在路上路过一家学院时不由自主的走了进去(魔法天赋被发现，“神”出手引导其进入)，随后在其中学到了不少未曾听闻的知识，并第一次产生了“我还想再来”的念头，不知不觉间在一次次进入学院中逐渐摆脱了梦中人浑浑噩噩的状态，随后正式被收入学院，也见到了几位同学。  
极乐世界有两名领导者，一位筑梦者，是创造梦境的人，他成为了梦境本身，失去了自我意识，也失去了生命。另一个净化者(引导者)，筑梦者的伙伴，负责清理乌云中堆积的负面情绪，可以自由出入梦境的同时在梦中拥有梦境赋予的永生，同样受梦境规则制约，但在梦中不可被看见(防止他在居民眼前出现，导致不稳定因素)。  
引导者在这么多年过去后看着日复一日狂欢着的人们开始思考这个“极乐世界”是否是正确的，现在的人们似乎完全不真的快乐，整个梦境每天产生的负面情绪都在不断增加，他开始思考这个梦境是否真的应该存在。  
引导者发现了“神”占据的学院，他观察了一段时间后确认了主角天赋是最好的，也是受梦境影响最小的。于是他选择了主角，开始用各种方式旁侧敲击的告诉他:“这是一场梦，你必须醒来。”  
主角意识到后开始尝试用各种方式离开梦境，这个行为被“神”发现了，他们在继续教授主角的同时，开始着手研究离开梦境的方法。  
过了一段时间，研究毫无进展，这时引导者找上了几位“神”，他的行为已经开始被梦境察觉了，他为他们提供了一道魔咒，那便是离开梦境的方法。他告诉他们，还需要一道躲避检测的魔咒，需要她们自己研究。  
随后他去到了主角现实的家中，准备给他留一封信，但就在他刚拿起笔时，梦境的抹除到来了，因为在梦境外，抹除的威力有限，他死在了原地，但尸体没有消失。  
“神”在长时间实验无果后决定合力强行接出主角，主角经过长时间学习后完全明白了现在的处境，但由于仍在梦中，他并没有产生任何负面情绪，只是保持着一种诡异的平静，不断尝试着离开梦境。(梦境的检测没有触发，因为他的尝试并不可能成功，也危害不到梦境，所以没有被视为不稳定因素)  
“神”布设好了法阵和魔咒，主角到来时他们合力发动，主角瞬间就被送出了梦境，但抹除也同时到来，几位“神”合力抵挡，都受了重伤。他们告知了主角一切的情况，并向主角讲了最后一堂课，随后便回到他们的据点养伤。  
主角并不明白为何他们执着的想要关闭梦境，他先回了一趟家，发现了引导者的尸体，但他并不认识，他在他身上发现了一张用途不明的卡片，以及一只掉落在地的黑笔和一张只写了一笔的白纸。  
他开始在世界上探索，寻找有关梦境的痕迹，看着支离破碎的城市，提防着各种致命的危险生物，他开始想:“我何必出来呢，在梦中至少我不必畏惧死亡。”  
他不断地探索，见过了许多梦中之人入梦前的日记，书信，遗物，他开始理解现实世界的意义，也开始明白了“神”们想要关闭梦境的原因。  
他在一个隐藏的地窖中找到了第一条关于梦的线索，并顺着线索一路追寻。  
漫长的探索后他终于在一座防守严密，机关重重的地牢中找到了一座经历了漫长岁月但依旧完好的法阵，法阵中央保护着一颗水晶球(筑梦者化作的)，正是梦境的核心，在其上还能看见梦内的景象，他在水晶球前踌躇良久，最终还是念出了那个咒语 —— 关闭梦境  
梦中的所有人都听见了那道魔咒，与此同时梦境开始崩塌，人们一个个的消失，回到了入梦前自己所在的地方，有人认出了那道声音，正是主角。  
主角发现梦境中还有许多小云没有清除，于是他又开始了漫长的探索，每每遇上别人，总少不了挨一场骂，或挨几下打，而他只是安静的继续走着。  
终于，在主角摧毁所有梦碎片的那一天，梦中的一切全部都被清空，他盯着手中的水晶球看了很久，随后用力地把他丢了出去，它在地上摔的粉碎，这场梦彻底结束了。
