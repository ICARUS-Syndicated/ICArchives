# 附录 - 服务器点歌指引

## MOD的安装

1. 群文件内 服务器点歌文件夹 内下载符合你游戏版本的MOD  
2. 将这个MOD安装到你的游戏里面  

如果你使用的是原版客户端，那么请下载并安装fabric或forge  
如果你已安装，那么下载文件名中带有对应标识（fabric/forge）的MOD文件  
安装方法：将下载的mod文件放到游戏内的mods文件夹内（xxx/.minecraft/mods）  
注意：fabric版本同时需要fabric以及fabricAPI! 群内提供API文件，安装同上  

## 点歌的操作

首先，禁止点国歌，点了直接BAN ，理由详见《国歌法》  
 其次，答应我这个卑微的服主，不要点那些奇奇怪怪的歌好嘛  
最后，由于技术问题，在播放歌曲时进入地狱门、使用望远镜时的图像显示会异常，播放唱片、音符盒时会无声，可通过stop或nomusic指令解决，具体介绍见下文  

如果你在点歌后或切歌后看到这样一个界面，那么恭喜你安装成功！  
如果你进入服务器后没有出现界面不要着急，可能是因为没人点歌或者当前歌曲没有放完，直接点首歌或者耐心等待一会并询问一下服内的hxd们当前歌曲还剩多久或直接投票跳过该歌曲（投票过程见下）  
若出现切歌提示（正在播放：XXX）后还是没有该界面，则说明MOD冲突或安装未成功  
已知冲突MOD:所有的作弊MOD 旧版的投影(litematica)  
直接点歌：  
指令 /music \<歌曲ID>  
  Q:什么是歌曲ID?  
  A:allmusic使用网易云音乐API，而网易云里面的每一首歌曲都有一个独一无二的歌曲ID（所以不要想着点某狗某Q的歌）  
 ID查看方式：分享歌曲-复制链接  
示例： 歌曲 丑八怪-薛之谦 的分享链接：  
[http://music.163.com/song?id=27808044&userid=XXXXXXXX]  
红色部分为歌曲ID，蓝色部分为用户ID  
使用指令/music 27808044   即可直接点这首歌  
搜索歌曲：  
指令 /music search 歌曲名  
示例： 当想听歌曲《older》时可输入指令：  
/music search older 执行后会出现以下画面  

点击对应歌曲后该歌曲就会被添加到播放列表  
切换歌曲：  
指令 /music vote  
这个作用是投票切换到下一首歌，需要至少三名玩家投票方可跳过（真不喜欢但又想一起听可以使用/music stop）  

关闭听歌：  
指令 /music nomusic  
这个指令可以让你不再参与听歌活动。执行后服务器将不会向你推送任何有关点歌的消息（不推荐，大家一起玩的就是一个氛围）  
要是你后悔了就 点一首歌，或发起投票就可以继续听  
指令 /music stop  
这个指令可以暂时让你停止播放这一首歌，等到下一首歌时音乐会恢复播放
