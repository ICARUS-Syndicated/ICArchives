# 第一迭代

> 悄悄地我走了，正如我悄悄地来；  
> 我挥一挥衣袖，不带走一片云彩。

一个服务器的名字，在它还活着的时候就已经没人说得清来历；等到它死了，名字反而成了唯一留下来的东西。  
一个连生日都要另找一天来过的服务器，后来被那么多人叫作「家」，这中间的距离，是平均一天接近 1000 条聊天记录所无法概括的真实。  

本文档能够作为考据依据的，只有笔者电脑上残存的接近60天的日志，先前 ICAI 已经完成的纪实工作，两三张留下来的图片以及所有曾经参与过 ICAI 文档修订与各位的记忆。谬误之处，还请见谅。
