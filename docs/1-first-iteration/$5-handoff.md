# 交接棒

服主走了，服务器没有立刻散。三月的日活还有二十五人左右，但是随后这个数字将会快速小下去。与此同时，管理层正在开始缓慢的交接。  

红白在的时候几乎完全承担了所有职务。走之后，权限碎了个稀巴烂：欧阳远怡有 Owner 的名分，CBW 是代理服主，wer 有过代理服主的头衔和一串后台权限，air 有管理员权限和一台能直接覆盖存档的实体机，huxk 在三月十三日拿到了管理员。这些名字在日志里轮流出现，做的事差不多：封人、回档、答疑、修插件、拉新人。没有人能像红白那样一句话定调，于是每一件事都要乱七八糟地商量，商量不出来就按各人的习惯办，和小孩子玩家家酒一样在像大人一样处理。  

白名单是这一期最重要的一项制度。它从二月十四日开始播“服务器即将开启白名单”，一直播到三月五日还是“即将”。三月四日傍晚，huxk 给出时间表：“服主要搞白名单了”“回来就开始”（日志 03-04 18:40）。十天后，白名单以最原始的方式落地：管理员手工打 `./whitelist add`，一次四个人，非常之原始。  

这一期也是熊孩子最多的一期。二月二十六日到三月二十七日，被永久封禁的账号有九个，被永久警告的有三个。  
老玩家也在渐渐地没入水底。三月的日活高点里，一半是当月才进服的人。老人一个一个地不来了：苏哥、wsts、Black_Cat 只偶尔露头，air 在三月二十日丢了 op，wer 在三月十八日丢了自己全部的物品。  

## 混乱

二月十四日晚上九点零七分，huxk 推出黑山的身份标记制度：“所有还记得自己是黑山基地的成员 请马上领取身份标记 否则无法受到保护并一律抹杀”（日志 02-14 21:07）。标记的做法是把手里的东西改名成“α-部门-游戏名”，部门有科技、建筑、冲锋、安保、后勤、人事、劝架。这是有记录内黑山官僚制度的直接体现。  
同一天晚上十点十一分，白名单的广播第一次出现：“！服务器即将开启白名单！”“请及时加入QQ群963406844”“没有QQ可向管理申请白名单”（日志 02-14 22:11）。

二月二十五日，人口掉到十七，新人欢迎零次。15213571 在公屏上说了一句让所有人都不太舒服的话：“5天黑山就只有一个我一个人在活跃”（日志 02-25 20:01）。

二月二十六日晚上九点四十，Werewolfwolfy 永久封禁了 king_ken，理由当然是一句模板：“您已被判定为熊，加群963406844申请解封”（日志 02-26 21:40）。  
随后是回档协商，对话里有一段很能体现当时的运维水平：“半径一个区块吧”“152个区块”“co rollback是按照区块为半径回档”（日志 02-26 21:41）。  
十点三十二分，huxk 私聊 wsts：“你没看见黑山基地传送价格改成8w了吗x”（日志 02-26 22:32）。十点三十五分，他列了一份名单：“最近红白阁成群结队来熊服务器的很多”，majang、king_ken、zhushen_huanghui、cc_iostream，“死了三个但是中间的没法定罪”。

三月四日傍晚六点四十，huxk 宣布白名单要来了。LRY314 的第一反应很实在：“那我挂机用的小号不是废了”（日志 03-04 18:40）。七点四十四分，白名单广播如期出现，huxk 说“这不就来了吗”。  
同一晚七点二十九分到七点三十三分，LRY 在公屏上把蒟蒻基地的家底交代了一遍：“蒟蒻真的干事的没几个，dai,sun,yjg三个摸鱼”，这是有记载的对蒟蒻基地的直接描述。十点三十八分，他切到职业战争子服，客户端列出可用的服务器：bedwar、main、occwar。

三月十一日晚上八点三十三分，服务器挂了 130 秒。wer 在公屏上报 `The server has not responded for 130 seconds! Creating thread dump`，huxk 喊“连着炸了两个服务器??????????”（日志 03-11 20:35）。  
当晚的故障还有：`Cannot execute command 'ah' in plugin AuctionHouse v3.1 - plugin is disabled`、`文件没被正确挂载`，点歌插件也失联。十点十八分，欧阳在后台谈租服务器：“找个管理去买个腾讯云”“211一年的那台”“买两台4g的吧”（日志 03-11 22:18—22:20）。或许二周目就是在这个时候开始进行策划的，但是没有任何直接证据。  

三月十二日晚上九点三十二分，服务器的总金额显示为**负的两千亿零九十一万**，一个人的余额是一千九百九十九亿九千五百八十万（日志 03-12 21:32）。这个数字此后再没变过。  
同一天，astx 被多人指认拆过 hmcl、yjgdjsy、LRY314、蒟蒻与黑山，air 永封了他，随后在这场误会化解之后，四十八分钟后又解封了 astx。LRY 给他的建议是“有条件可以装一个投影mod学学网上的机器”（日志 03-12 22:29）。  
附注：现在 astx 是非常强的生电大佬。  

三月十三日下午六点十七分，huxk 在公屏上宣布：“我现在是管理了”（日志 03-13 18:17）。四十天前，wer 还在说“我不干了”。没有鲜花也没有掌声，这位后来的二三周目承担了绝大多数开发的管理员就这样安静地走上了属于他的位置。  
同一天，wer 因为换微软账号“整活整大了”丢了管理权限，自称“残疾op”。晚上七点十九分，huxk 发现 LWC 的漏斗漏洞，现场打出 `./lwc flag hopper on`，ludenghua 的评价是“机器不怕被白嫖了”“152狂喜”（日志 03-13 19:19—19:26）。尽管后来 152 并没有使用这个方法。  

也就是在这个时间点，代理腐竹 Werewolfwolfy 出现了崩溃症状，主动选择了辞去代理腐竹的职务，选择降级为工作较为轻松的管理员。  
三月十八日是 wer 的灾难日。红白帮他转微软账号，转完之后“转了个UUID”，他的物品全没了。晚上八点二十三分，他在公屏上写“i lost my all !”“I TRIED!!!!!!!!!!!!!!!”（日志 03-18 20:23），随后宣告“我服了，退服了”，整晚情绪崩溃，“我用forceOP撬了红白的账号”“我直接远控服务器”“想逃也逃不掉（关服）”。air 一边安慰他，一边在 LuckPerms 里给他调权限组。  
同一晚，kimmyjustkimmy 以新人姿态领走了 yjgdjsy 一把命名为 `<Kimmy Bow>` 的满配弓（日志 03-18 19:59），自称在带一个叫 madventures 的同学。

八点零六分，huxk 在公屏上说“有几个jb把wsts的潜影贝农场炸了”。
三月十九日上午十点四十九分，linheng_li 报“这家伙把猪人塔bear炸了”“bear了还不承认”“还在哪里装好人”（日志 03-19 10:49—10:50）。huxk 用 CoreProtect 查到凋零骷髅塔也是同一个人干的，十点五十三分、十点五十四分两次永封 kimmyjustkimmy，十一点整封了 nidniananw1d，理由是“祸害凋零骷髅塔”。回档的事没有做成。huxk 说“回档就炸”，linheng_li 补了一句“生电机器回不来档的”（日志 03-19 10:53—10:54）。  

也就是在这个时候，直接导致 wer 退服的整蛊事件发生了。  
在 3 月 19 日的下午笔者萌生了恶作剧的心思，向 wer 索取了管理权限。由于 wer 权限不足，其遂而转向向具有管理权限的 Airlenter 索要权限。然而在游玩时，笔者不慎清空了 ludenghua 的背包。  
同一天下午四点五十分，ludenghua 在公屏上报“我在天上飞着 开着背包 啥都没看见 啪 东西没了”（日志 03-19 16:50）。四点五十九分，huxk 私聊承认：“我开troll给他背包物品卸了”。五点整起，欧阳在一串挂在“[公告]”前缀下的句子开始追责：“哪个哈皮用整蛊插件?????”“TMD谁给的整蛊权限”“WER你给整蛊权限干啥”“谁给HUXK上的个人权限”（日志 03-19 17:00—17:06）。“[公告]”是欧阳远怡的聊天前缀，三月十三日他自己解释过：“这个是我讲话用的”“前缀叫公告而已”（日志 03-13 17:44）。  
ludenghua 在这期间只说了一句话：“生存服教训：不要突然把插件糊到生存玩家脸上”（日志 03-19 17:04）。  
晚上七点四十八分，huxk 宣告“啊对了忘记说了 文件级回档了”，紧接着 Esrafv 的末影螨、鹦鹉、合金甲尸壳和 LRY314 的头盔接连消失。这是因为 CoreProtect 恢复不了玩家背包，文件级回档又会连带删掉别的东西；后来，air 被降级为协管，而 wer 被清空全部权限。较为矛盾的是，事件的直接导致者，笔者，却仅仅只是被批评教育。四十天后，同一批人当然还在这个服务器里，只是没有人再提这件事。  
更为详细的事件记录参见[此处](troll-incident-report.md)。  

在此之前，kimmy 开始找理由在群内给自己求情。九点零四分，air 对永封标准提出异议：“就普遍理性而论，你这永封标准有点高了x”。九点四十一分，godethan 求情成功，kimmyjustkimmy 被解封，二十七秒后再次永封，理由是“熊凋零骷髅塔和猪人塔”，huxk 自己称之为“鞭尸”。十点零三分，他让 wer“把子服也关了”，因为他“不想听kimmy在那边瞎jb白扯了”，因为 kimmy 还在起床战争和职业战争里骚扰他。  
三月二十日晚上八点十三分，godethan 转告“kimmy要和你谈谈”，huxk 连说“免谈”“要么换个号 要么别玩”。八点三十五分，新号 fuckingmojang 进服，先嘴硬“对对对，我熊”，被 15213571 一句“封了吧”顶回去后改口“我不敢凶了”（日志 03-20 20:37）。huxk 给了他白名单，不还东西，说“当个教训”，kimmy 应“那真是个严重的教训啊”。九点零八分，kimmyjustkimmy 被解封，huxk 说“kimmy记住没有瑕疵了啊”（日志 03-20 21:08）。九点四十七分，godethan 当场收留他：“kimmy来我这里发展吧 这里地方你随便找”（日志 03-20 20:47）。  
三月二十五日晚上七点五十八分，kimmy 的求情终于失效了。在证实其使用第二个号肆意破坏之后，其两个号同时永封，理由只有一句：“再见了没妈的东西”（日志 03-25 19:58）。随后是两个小时的 CoreProtect 回滚，检查器反复扫出生点与地狱的偏远坐标，记录里 kimmy 在七天前放置和破坏了下界合金块，回滚几千件物品，中间夹着“数据库繁忙”。同一天晚上，madventures 私下提醒 huxk“他可能进来后，会炸图”“我是偷听到的”。  
然而后来却什么都没发生。  

十点十六分，红白在后台试了三次 pure：“试一下server pure”，系统回“指定的服务器 pure 不存在。”，十点二十三分他说“好吧，我先溜了，bye”（日志 03-25 22:16—22:23）。这是他最后一次在有记录的日志里出现，虽然只是后台的一行字。  
交接没有仪式。日志里没有一条关于服主转交的记录，甚至也没人能知道管理群里有没有开过小会，更新摘要里甚至只有三行字：“原服主RedWhite因考试将服主身份转移至欧阳远怡”“CBW为代理服主”“（实际上还是hu这个屑逼在维护大部分东西）（悲催打工人）”。这三行字没有日期。  
一个服务器的所有权，就这样在轻飘飘的三行字字里进行了无人知晓的交接。
