# 蒟蒻基地

由 LRY314、XiaoMaome_ya 等人建立的基地。  

## 记事

由lry314,Xiaomaome_Ya等所创立的基地。  
成员构成在日志中出现过更加详细的描述：LRY314 说"蒟蒻真的干事的没几个，dai,sun,yjg三个摸鱼，还有的只玩一次就退"。yjg 即 yjgdjsy，XiaoMaome_ya 是 LRY 同学（leavepure）的妹妹（"那个，Xiao不是我同学，是同学的妹妹"）。

蒟蒻没有对外设置开放地标，2022-03-13 LRY314 自己发送过如下消息："蒟蒻有密码锁他们怎么来的""没warp他们怎么去的"。  
蒟蒻建设有一栋相当大依山而建的京派楼宇，但是未得到保存；有一条盘旋雪山而上的橡木步道，于半山腰处留存有半山亭，亭内留存有“惊喜”椅。  
基地主体基本由各种机器堆叠而成，用材较为随意。  

关于蒟蒻基地以及其有关事件：

2022-01-28 发生过树场冲突。XiaoMaome_ya 在白桦树场种橡木、又用上锁箱子堵地狱门，顶坏 LRY 的树机。LRY 早上骂人并威胁封号，Xiao 退服。当晚 LRY 托 huxk 转达道歉长文："Xiao，很抱歉早上骂你还威胁封号，我现在明白同学情比游戏更重要……请你回来吧"。机器最后由 LRY 自己修。  
2022-03-12 发生过被破坏事件。LRY 所言："bear全来蒟蒻了"。位于末地的蜂蜜机被盗窃，甚至一周里"已经无了11个熊孩子了"。
