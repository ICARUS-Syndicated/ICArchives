# 终末基地（The End Base / 终末基地）

> **类型**：玩家基地（一周目第一起熊服事件的现场） ｜ **主导者**：linheng_li（旧名 HLpixel，ICAI 文档编辑者之一） ｜ **存续**：一周目前期；"熊孩子被 ban 之前"，早于 sb737 事件 ｜ **地点**：无 warp、无坐标 ｜ **规模**：有凋零骷髅农场、全物品与其他机器

## 一句话

一周目第一次被系统性熊掉的基地；主人没有重建，直接摆烂。

## 由来

ICAI 只有一句带括号的交代："终末基地（linheng_li创建，被熊后直接摆烂）（时间线顺序在熊孩子被ban之前）"（[ICAI 第 815 段]）。下一段给出它在作者记忆里的位置："（似乎是我进入服务器的第一次熊服事件，在sb737事件之前）"（第 816 段）。
这是全站 17 个组织条目里资料最少的一个：没有建立时间、没有位置、没有成员、没有组织形态，只有一次事件与一份损失清单。

## 组织形态

不存在"组织形态"。可推知的只有设施——ICAI 的损失清单列了三类："毁坏凋零骷髅农场，炸掉全物品，炸掉其他机器等"（[ICAI 第 817 段]）。"全物品"指分类全物品仓库，是一周目生电玩家的标准配置；凋零骷髅农场是刷头颅的机器。两者同时存在，说明这是一座投入不小的生电基地，而不是临时落脚点。
"摆烂"在这里是字面意思：被熊之后没有重建、没有追讨、没有转移，基地事件就此结束。

## 关键事件

- **第一次熊服事件**：时间在 sb737 之前，具体日期无记录。破坏项见上（[ICAI 第 815—817 段]）。
- **熊服者的手法**："这货开多号扮演不同角色甚至不同性格来当内鬼搞破坏，后面被我和hour揭穿急眼了炸了基地，当时气走了部分人，二周目都回来了"（[ICAI 第 819 段]）。这一条同时给出了三点：多开、内鬼、被揭穿后炸基地。
- **后果**：基地被炸、部分玩家离开；ICAI 说这些人在二周目都回来了。
- **日志侧的 linheng_li**：他在 2022-02-01 才首次出现在语料里，03-13 基地再次被抄（"基地里现在只剩下我和另一个人了""其他全tm是熊"，指 Ezzzzz、zxjz、NanMu、Qinian_suolin 等人），03-19 猪人塔又被 kimmy 毁掉，同日晚因在工业区白嫖吃永久警告。这些是否发生在"终末基地"这一处，无法判定。

## 与他者的关系

- 与 Hour2（hour）：**共同揭穿内鬼**的人。ICAI 写"被我和hour揭穿"。
- 与 huxk2008：记录者，也是揭穿者之一；这段文字由他写。
- 与 kimmy 系列：ICAI 的熊服事件编年把终末基地排在 sb737 之前（第 815—816 段），而 kimmy 的 ID 名单里就有 sb737（第 828 段）。也就是说，破坏终末基地的人**未必**是 kimmy，两起事件只是被写在同一节杂谈里。这一点常被混淆，须分开。
- 与 [大会要](大会要.md)、[黑山基地](黑山基地.md)：无任何关系记录。

## 衰落与遗产

没有遗产。基地没有重建，主人继续在服务器里玩到 3 月（还做合金生意、给新人当电工），但那座基地再没被提起。
它留下的是一条时间坐标：一周目的熊服史从它开始，往后是 sb737，再往后是 2022 年 3 月的 kimmy 潮。ICAI 把它当作"第一次"来记，这个"第一次"的价值大于基地本身。
