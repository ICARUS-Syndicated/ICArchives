# 沙漠小镇

由 HBGL、2830484880 所建立的基地，但是在黄金时期之前已经消失在了沙漠中。

## 记事

沙漠小镇大概是一周目最早消失的那批基地之一，没有留下确切传送点。  
由于确切的消息过少，只有能确定是由 HBGL 所建立的基地，且在黑山之前沙漠小镇就已经消失在了沙漠里。不明确建成年份，无消失原因，也找不到位置。HBGL 本人在语料里对它几乎不谈，只在 2022-01-03 公屏留下三个字加一个表情："沙漠小镇qaq"。  

沙漠小镇属于早期聚落，没有形成类似黑山的组织制度。可确认的只有后期回忆的部分：  

- **空中基地**："这里还有一个后修下去的空中基地，似乎主要的居民是283吗？应该还有其他被我遗忘了的人吧。"
- **283 的房子**："ta有一间，白色的现代风屋子，屋子里面，有温泉吧。"hot_doggy 说自己在附近"放置了某种矿物块，大抵是钻石或是合金，来吸引283的注意"。
- **蜂场与蜂巢**：283 的蜂场是"模拟森林环境的温室房间，有玻璃顶"，而且"似乎不是一开始就是那样，因为我捕捉过出逃的蜜蜂"。hot_doggy 在旁边修了一只很大的蜂巢，顶部装了"很好笑的自动蜂蜜机和会自杀的骨粉机"，也是他"第一次尝试自己做内饰的试验场地"。
- **地形**：一片岩浆浇筑的围墙；河边的草地上种过竹子；"那个时候没人想搭理这个坑坑洼洼的地表"。

以上信息来自 hot_doggy。

## 衰落

没有任何确切证据可以说明是何时消失的。  
遗产是一处"叠加"的景观：地表的沙漠小镇没了，空中的基地、283 的白色房子与温泉、温室蜂场、那只巨型蜂巢还在，但是并没有被档案馆所收录。
