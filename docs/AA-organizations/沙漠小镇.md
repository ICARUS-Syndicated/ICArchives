# 沙漠小镇（Desert Town / 沙漠小镇）

> **类型**：早期玩家聚落（已消失） ｜ **主导者**：[HBGL](../players/HBGL.md)；后期空中基地与 [2830484880](../players/2830484880.md) 相关 ｜ **存续**：一周目前期，在黑山兴起之前即已消失；空中基地更晚 ｜ **地点**：沙漠，无 warp、无坐标记录 ｜ **规模**：不详，无成员名册

## 一句话

一周目最早消失的那批基地之一；等后来的人想去找，连沙漠都找不到。

## 由来

ICAI 只有一句："由HBGL所建立的基地，在黑山之前沙漠小镇就已经消失在了沙漠里。"（[ICAI 第 134 段]）没有建成年份，没有消失原因，也没有位置。HBGL 本人在语料里对它几乎不谈，只在 2022-01-03 公屏留下三个字加一个表情："沙漠小镇qaq"[日志 2022-01-03 14:47]。

## 组织形态

早期聚落，没有制度记录。可确认的只有后期叠加上去的部分：

- **空中基地**："这里还有一个后修下去的空中基地，似乎主要的居民是283吗？应该还有其他被我遗忘了的人吧。"（[ICAI 第 135 段]）
- **283 的房子**："ta有一间，白色的现代风屋子，屋子里面，有温泉吧。"（第 136 段）huxk2008 说自己在附近"放置了某种矿物块，大抵是钻石或是合金，来吸引283的注意"（第 137 段）。
- **蜂场与蜂巢**：283 的蜂场是"模拟森林环境的温室房间，有玻璃顶"，而且"似乎不是一开始就是那样，因为我捕捉过出逃的蜜蜂"（第 138 段）。huxk2008 在旁边修了一只很大的蜂巢，顶部装了"很好笑的自动蜂蜜机和会自杀的骨粉机"，也是他"第一次尝试自己做内饰的试验场地"（第 138—139 段）。
- **地形**：一片岩浆浇筑的围墙；河边的草地上种过竹子；"那个时候没人想搭理这个坑坑洼洼的地表"（第 143 段）。

## 关键事件

- **黑山之前消失**：ICAI 的时间定位（第 134 段）。这是它唯一被给出的时间信息。
- **2022-01-08**：2830484880 在公屏问"沙漠小镇的和hour小岛的坐标"；BingMax 接"都找不到沙漠"[日志 2022-01-08 22:28—22:42]。要坐标，说明连常住民也回不去了。
- **2022-01-16**：2830484880"沙漠小镇没了我的家底直接给截断了"[日志 2022-01-16 17:01]。这是他对自己在那里的财产的总结。
- **2022-02-01**：sun_fire_cloud 在公屏连喊"沙漠小镇啊啊啊啊啊啊""我就是想知道沙漠小镇在哪里，我的家产权在哪里了"[日志 2022-02-01 13:43、14:39]。一周目后期仍有新人在找它。
- **蜂巢的两起事故**：内饰的蜂蜜块滑道被 [Hour2](../players/Hour2.md) 窃取，"然后以很糟糕的方式归还摆放"；被邀请入住的新玩家"入住后即刻退服，并留下一片锁住了打不开的箱子"。ICAI 的结论是"这个蜂巢还真是厄运连连"（第 140—142 段）。
- **与 283 的决斗**：huxk2008 在河边与 283 决斗，"途中不幸失去了一点也不忠诚的三叉戟（大概丢了两次？这也是我兴建溺尸塔的理由）"（第 144 段）。

## 与他者的关系

- 与 [HBGL](../players/HBGL.md)：创建者。他后来几乎只出现在起床战争与悬赏里，很少提旧基地。
- 与 [2830484880](../players/2830484880.md)：后期居民。他把"家底"放在这里，基地消失等于财产被截断；他与 [HBGL](../players/HBGL.md) 也是全期关系最稳定的一对（睡觉、悬赏、互损）。
- 与 [Hour2](../players/Hour2.md)：邻居式往来，偷滑道那次是纯恶作剧。
- 与 [黑山基地](黑山基地.md)：时间上的前后脚。ICAI 用"在黑山之前"给它定位，说明在作者的历史排序里，沙漠小镇属于"前黑山时代"。

## 衰落与遗产

消失得干净：没有废墟描述，没有回档记录，没有重建。ICAI 写"沙漠小镇没了"，玩家写"家产权在哪里了"，两种说法都指向同一个结果——地盘在没有领地、没有备份承诺的年代里可以直接不存在。
遗产是一处"叠加"的景观：地表的沙漠小镇没了，空中的基地、283 的白色房子与温泉、温室蜂场、那只巨型蜂巢还在，成了 huxk2008 一周目记忆里最细的一段（[ICAI 第 135—146 段] 全是他第一人称）。

## 史料备注

- **日志实证**：HBGL 的一句"沙漠小镇qaq"；283 要坐标、说家底被截断；BingMax 找不到沙漠；sun_fire_cloud 追问"家产权"。
- **ICAI 回忆**：HBGL 创建、"在黑山之前消失"、空中基地与 283、白色房子与温泉、蜂场温室、蜂巢的自动蜂蜜机与骨粉机、蜂蜜块滑道被 hour 窃取、退服新玩家与锁箱、岩浆围墙、竹子、决斗与三叉戟。
- **推断**：沙漠小镇与空中基地是同一片沙漠上的两代建筑；283 是空中基地的主要居民。
- **查不到的**：坐标、建成年份、消失原因、成员数。语料里"沙漠"14 次，多数指地形而非这个基地；线上组织页此节为空。
