# 繁樱屿

五六周目由 `QAQ121QAQ` 创办的最大的聚落，也是五周目末期最大的在建工程。  
在已知记录中它有两个名字：**繁樱屿**与**徽樱谷**（六周目新址，暂定名）。  

## 五周目

2026.2.3 `agonicx330ml` 开始建“樱花小屋”，是繁樱屿的第一个建筑。  
繁樱屿已知设施有龙亭、伊蕾娜/银狼/神子三座手办、樱花亭、附魔亭、鸟居、交易所、64 核熔炉、刷铁机、自动农田与牧场、潮涌核心、移山造工业区。
繁樱屿原本的规划中有四个大区，但是无法从聊天记录中推知。  

## 六周目

三月二十一日，`agonicx330ml` 宣布“我要脱离繁樱屿了，QAQ”，理由是 QAQ 长期不上线。  
三月二十二日，`agonicx330ml` 发起“移山工程3期”，`WASP`、`NewBie_Bu`、`Hydro_Slime`、`zhenenji` 参与了工作。新址定名“徽樱谷”。  
原本的计划建筑群中有星陨极轨塔、谧湖樱台、徽派建筑群、公路网、环山栈道、樱月京塔。  
四月十三日，`agonicx330ml` 告别，因此星陨极轨塔工程随之烂尾。  
此后衰落。  

## 内部结构

繁樱屿是五六周目唯一一个产生了较为详细分工的组织：

- `QAQ121QAQ`：岛主  
- `agonicx330ml`：主力建筑师  
- `zhenenji`：工业  
- `Potassium_ClO4`：水下工程  
- `SANE`、`maimai`：新人
