## 一 · 一周目

#### 一句话

一周目最有名的"别人家的基地"：一台巨大的刷铁机、一箱没人说得清来路的内测物品，和一个早已不上线的名字。

#### 由来

ICAI 只有两句："Minecrft24K 的基地，也是前期的一个比较大的基地，印象最深的的是它的巨大的刷铁机，以及箱子里面的一堆神奇内测物品。"（[ICAI 第 131—132 段]）没有建成年份、没有成员、没有组织形态。这个条目之所以能写，全靠别人在公屏上提到它。

#### 组织形态

- **一人所有**。60 天语料里 `Minecrft24K` 这个 ID **一次发言都没有**（`stats.json` 187 个发言 ID 中不存在），只在 LWC 锁箱提示与他人提及里出现。
- **对外接待**。地标名为 `minecrft24k_guesthall`——"客房厅"，说明它设计过访客动线，是被当作参观点开放的。
- **机器**：巨大刷铁机（ICAI 唯一记得的设施）。旁证是玩家对"255 附魔"的追问（见下），说明基地里还有非常规物品。
- **锁**：熔炉等容器用 LWC 上锁，主人不在、锁还在。2021-12-31 与 2022-01-29 共出现四次"注意：这个私有的 熔炉被 Minecrft24K锁起来了"[日志]。

#### 关键事件

- **2021-12-31**：玩家在别人的基地里点到上锁的熔炉，系统提示主人是 Minecrft24K[日志 2021-12-31 18:36]。这是语料里关于这个基地最早的一条痕迹。
- **2022-01-25**：[Werewolfwolfy](../players/Werewolfwolfy.md) 在聊红石时说"不然24K直接整出矢量珍珠炮了awa"[日志 2022-01-25 21:53]。人不在场，技术名声还在。
- **2022-01-29**：连续三条熔炉锁提示（19:57、19:58、20:02）[日志]。同一天 [LRY314](../players/LRY314.md) 说："我给24K贴'福'他看不到吧……这人很久没上线了……"[日志 2022-01-30 21:59]。这是"主人已离线"的直接证据。
- **2022-02-01**：[Hour2](../players/Hour2.md) 带 [15213571](../players/15213571.md) 参观，"15213571./warp minecrft24k_guesthall"连发两遍[日志 2022-02-01 14:23—14:24]。它仍是新人参观路线的一站。
- **2022-02-18**：LRY314 问"硫酸铜，HBGL，24K他们的255附魔是怎么得到的"[日志 2022-02-18 20:45]。与 ICAI 的"神奇内测物品"互相印证，但没人回答来源。
- **2022-02-25 / 03-12**：LRY314 两次把它列进参观点——"warp里面黑山，苏维埃，24K可以参观一下"[日志 2022-02-25 19:26]；"这个好像是24K的"[日志 2022-03-12 21:48]。

#### 与他者的关系

- 与 [黑山基地](黑山基地.md)、[苏维埃联盟中央指挥部](苏维埃联盟中央指挥部.md)：**并列的参观点**。LRY 的那句"黑山，苏维埃，24K"把三家放在同一个清单里，说明在玩家心里它是"老牌大基地"之一。
- 与 [主城](主城.md)：经济上的间接关系——"255 附魔"这类物品的存在，是主城经济失衡的一个侧面证据（OP 级物品在玩家间流通）。
- 与 [农场](农场.md)：同类（生电基地），但农场一直有人打理，24K 早已无人。
- 无资助、无从属、无冲突记录。

#### 衰落与遗产

它没有"衰落"的过程，只有"主人不来了"这一个事实。基地被完整地留在那里，容器锁着，地标还开着，成了公共参观景点——这种"人走了、建筑还在、谁都能进但谁都不能开箱"的状态，是一周目后期很典型的一种遗存。
遗产是那批"内测物品"的传说。它被反复提起（"255附魔""矢量珍珠炮"），却没有任何一件被记录下名称或来源。
