# 翠璃轩风闻司

具体而言，翠璃轩原本是五到六周目计划内研发的 RPG 服务器，以中式武侠为主。  
风闻司为这一世界观下的情报组织。  

## 内容

翠璃轩是一个虚构的修真世界：有医仙谷、药王谷、琉璃台、筑署、风闻司、还魂会、混沌侵蚀、末法时代。  
风闻司是这个世界的**情报档案机构**，负责收集、誊抄、批注、归档。  
《蒹葭》写的是一个医仙堕入药王谷的人物志：白衣医仙蒹葭，在医仙谷式微后成为药王谷执事，掌管秘药研发与对外大宗交易。  
《钰·〇》是一篇元小说：一个文书吐槽自己所在机构的档案几乎都不是自己人写的。  

除此之外我们尚未收集到其它相关资料。  
这两篇东西与红白阁的实际历史没有直接关系，但它们出现在六周目的遗存里，而且个人认为这个粗糙的世界观已经有一定成色了。
