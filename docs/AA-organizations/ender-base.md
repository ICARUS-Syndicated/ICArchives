# 终末基地

由 HLpixel 所建立的基地，由于熊孩子屡次破坏而停止建设。  

## 记事

应该是一周目少数因为熊孩子系统性破坏而彻底放弃重建的基地（原文为“终末基地（linheng_li创建，被熊后直接摆烂）（时间线顺序在熊孩子被ban之前）”）。  
可确定的是终末基地建立在末地外岛某处，且设置了公开传送点。  
由于日志仅保存了近 60 日，linheng_li 在 2022-02-01 才首次出现在语料里，03-13 基地再次被抄（"基地里现在只剩下我和另一个人了""其他全tm是熊"，指 Ezzzzz、zxjz、NanMu、Qinian_suolin 等人），03-19 猪人塔又被 kimmy 毁掉。
