# 第二迭代

> “虚空的虚空，” 传道者说， “虚空的虚空，全都是虚空！”  
> Vanitas vanitatum et omnia vanitas.  
> ———— 《圣经·旧约·智慧书·布道书》  

这一时期，是从混乱中重整，又从整合到混乱的过程。  
二周目是红白阁的第一次重生，在它之后，它又会重生很多次。  
对笔者而言，这只是一次漫长的凌迟处死。  

二周目只是是一具由插件或者是 mod 堆起来的尸体，被搬到云端、又被搬回某个孩子的卧室机箱里，靠一套比一周目现代得多的设备撑起来；它曾经在它最为混乱的时候迎来了它的辉煌，又在最稳定的时候迎来了它的死亡。  

由于数据损坏，本文档能够作为考据依据的关键的服务端自二二年七月至二三年一月上半的日志数据全部丢失，只能依靠留存下来的客户端日志，Velocity 代理端日志，先前 ICAI 已经完成的纪实工作，留下来的图片以及所有曾经参与过 ICAI 文档修订与各位的记忆。谬误之处，还请见谅。
