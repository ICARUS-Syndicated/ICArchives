断链

Ich bin von der Literatur weggesperrt, habe kein Interesse für sie... ich bin trocken, leer, besinnungslos..
我被锁在文学之外，对它毫无兴趣……我是干涸的、空虚的、失去知觉的……
———— Franz Kafka

六月二十一日，木白宣布“服务器也是终于release1.0了”。地标全部作废需重设、/hat 消失、home 迁移失败、称号改为“在线时间 2d 以上联系管理更换”。
改版之后，服务器上所有的地标都没了。地标是六周目唯一的交通系统。地标没了就等于全服的工业区、农场、村民交易所、矿场，所有的基础设施全部失联。
zhenenji 说：“这几乎约等于工业没有了”。

纪事​

六月二十一日，木白宣布发布 release 1.0。

“服务器也是终于release1.0了）”“但是好长啊（”
“都说了要重新设地标）”“放弃迁移了”

anioto 全程吐槽：“真就超级拼装”“不考虑整合一下吗”。
服务端从 Leaf 1.21.7 换到 Paper 1.21.11。插件表仍旧是 39 个插件，但换了一批：SunLight 终于被删掉，AxPlayerWarps、TPA、GSit、Hat、InvSeePlusPlus、PlayerKits2 加了进来。
这是三月三日那场未完成迁移的收尾。

六月二十二日，改版之后，服务器上所有的地标都没了。

zhenenji：“这几乎约等于工业没有了”
WASP：“家刚才炸的”
WASP：“屯的东西没了六分之一”

WASP 自己用 TNT 把家炸了。

六月二十三日，反作弊误判导致 Icy_Cola0406 打不掉方块，木白判断“可能是他没用1.21.11客户端”。
七月二日，dream 自述一个人在线。

dream：“平时很多时候就我一个人在线”
zhenenji：“我把建材蓄满我也走了”“无人了”“悲”

七月三日，qiuxin 入服，自称看到“木白发吐槽视频”来的。第一天就在询问基础信息：“服务器版本是多少”“1.21.11吗”。
七月十三日他讲出自己的来历：他是另一个服务器的管理，“原本是两边看看那一边混得好”“现在已经是另半边的管理了”。

七月四日，Icy_Cola0406 带 StarryOre 去看主城里一处不设地标、不标注的“存档区”；这上上个周目（四周目）的建筑被整体搬进本周目作纪念。

“能放的都是上上个周目”“这个相当于存档”“有纪念意义，就搬到这个周目了”
“曾经的大家，都很用心呢”

这是六周目最像“档案馆”的一刻：一个已经没有人玩的服务器，在主城地下藏了一座上一代服务器的复制品，不设路标，等着有心人去找[日志 07-04]。

七月五日到七日，zhenenji 修 5000 格铁路，连通繁樱屿工业区与“海盐奶盖雪原”（滚滚家），铺了 78 组铁轨。
七月七日通车，他给车站立了“人民铁路为人民”的标语。

“78组铁轨？！”
“大！基！建！”
“回头补一个人民铁路为人民”

他在同一天也说：“说实话”“我也不知道争这个干啥”“找点活干”。

七月十二日，同时在线到达五个人。zhenenji 说：“我去同志们”“人数最多的一次”。
同一天，Polar_Pioneer 发现自己的地标丢失，成了“流浪汉”：“我找不到我家了，现在是流浪汉awa”。

七月十三日，zhenenji 再一次锐评：

zhenenji：“都宁愿在群里发电”“也不来上线这一块”
Polar_Pioneer：“不过看似群里挺热闹但是来来回回活人就那几个”

zhenenji 还解释了为什么：“开荒的时候人多”“那一会真的有动力”“基础工业80%都是我们搞得”“现在做了也没人来”。

七月十五日，qiuxin 在聊天栏实时报延迟，基本都在 2000ms 以上且正在不断增加。Polar_Pioneer 接话“延迟飙五千了”“六千了”。

七月二十一日，木白在“改服务端源码”、重新编译、重启：“等我把改好的服务端编译好”“介意在重启下吗）”。

那为什么我拿到的 jar 的 SHA 和 paper 的是一样的呢？
还是说，你只是加一个 java agent 参数你就说成是改 src？
以及你的 java agent 真的很丑陋，一股溜溜梅味，下次不要弄了。
———— Ph0sphorW

同一天出生点周边被加了保护，Laugh_TheLiving 感到意外。

七月二十八日，Jinanfunny114 回归，第一件事是要称号“老登转世”。木白当场给他设了，并承认“可能真是最短得了”（在线时长最短拿到称号的人）。

七月三十一日，zhenenji 参观 Rain_neko 的家，被彻底震住：“肝上面长了个人？”随后提出“全自动农场印钞”计划，要把服务器变成“进服即毕业”：

“我选择直接上十几个叠加！！！”“给服务器上上强度）”
“貌似可以实现进入服务器即毕业”

同一天，Icy_Cola0406 逐个手动恢复被改版删掉的地标（猪人塔、海泡菜机、熟猪肉农场）。

八月八日，服务器里最后的热闹。在线有四个人：WASP、tianxiazaliangk、Jade_Emerge、527。他们大半时间在挂机。
WASP 说了两句像遗言的话：

“竟然是都在挂机吗）”
“下辈子面基猛猛陶你俩鸟窝（”

但是不会再有以后了。
